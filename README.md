# Workflows n8n

Automatisations construites avec n8n pour supprimer des tâches
manuelles répétitives en TPE/PME.

## Workflows

### factures-vers-tableur
Extraction automatique des données de factures reçues par mail
(montant, date, fournisseur) et insertion dans un tableur.
Gain estimé : 1 à 2 h/jour.*
